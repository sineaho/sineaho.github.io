Cineaho's
WebPrint

Cineaho's WebPrint는 웹페이지의 광고와 불필요한 부분을 제외하고 원하는 본문만 깔끔하게 인쇄 및 저장할 수 있는 편집 도구입니다.

정말 쉽습니다!
  1. 1. URL 주소 입력
  2. 2. 웹페이지 편집
  3. 3. 깔끔하게 인쇄!
북마크렛 사용방법

북마크렛: 브라우저에 Cineaho's WebPrint를 추가하여 즉시 사용해 보세요.

웹사이트 버튼: 내 블로그나 웹사이트에 인쇄 최적화 인쇄 버튼을 달아보세요.

회원 가입 시 다음과 같은 프리미엄 기능을 제공합니다:
  • 변경 세트 (Change Sets): 특정 웹사이트에 적용한 편집 옵션을 저장하여, 해당 사이트의 다른 글을 불러올 때도 자동으로 서식을 최적화합니다.
  • 클립 (Clips): 여러 웹페이지에서 마음에 드는 핵심 정보 문단만 수집(스크랩)하여 하나의 문서로 묶어 인쇄할 수 있습니다.
