🔑 애플리케이션 비밀번호 발급 방법

워드프레스 보안 연동을 위해 임시 비밀번호를 발급받아야 합니다.

  1. 본인의 워드프레스 관리자 화면(WP-Admin)에 로그인합니다.
  2. 좌측 메뉴에서 [사용자] → [프로필] (또는 프로필 편집)로 이동합니다.
  3. 화면 아래로 내려가 [애플리케이션 비밀번호] 섹션을 찾습니다.
  4. 새 애플리케이션 이름(예: Cineaho Poster)을 입력한 뒤 [새 애플리케이션 비밀번호 추가]를 누릅니다.
  5. 생성된 24자리의 비밀번호(예: abcd efgh ijkl mnop qrst uvwx)를 복사하여 좌측 패널에 입력합니다.
워드프레스 연동이 되어있지 않습니다. 상단 설정 영역에서 사이트 정보 및 애플리케이션 비밀번호를 입력 후 검증해 주세요.
