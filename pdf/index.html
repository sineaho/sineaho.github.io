PDF 병합/분할 도구 가이드

브라우저에서 직접 PDF 파일을 병합, 분할, 변환, 편집할 수 있는 올인원 PDF 도구입니다. 모든 처리가 로컬에서 이루어져 개인정보가 안전하게 보호됩니다.
100% 로컬 처리 파일이 외부 서버로 전혀 전송되지 않습니다.
빠른 처리 속도 클라이언트 최적화 엔진 탑재.
오프라인 지원 인터넷이 끊겨도 완벽히 정상 동작.

핵심 기능 목록

PDF 병합 (Merge)
  • 드래그 앤 드롭으로 간편하게 파일 순서 변경
  • 무제한 파일 개수 동시 병합 지원
  • 실시간 페이지 수 및 예상 파일 크기 출력
  • 병합 진행률 실시간 퍼센트 바 표시
PDF 분할 (Split)
  • 범위 지정: 1-3, 5, 7-10 개별 페이지 분리
  • 균등 분할: N페이지 크기별로 자동 분배
  • 개별 분할: 전 페이지 1장씩 별도 파일 절단
  • 부분 추출: 원하는 특정 썸네일 체크 추출
이미지 변환 (Convert)
  • 고품질 PNG 및 JPG 포맷 가변 출력
  • 품질 1~100% 압축 최적화 비율 지정
  • 해상도 72DPI, 150DPI, 300DPI 선택
  • 일괄 이미지 변환 후 단일 ZIP 파일 패킹
텍스트 추출 (Extract)
  • 전체 문서 혹은 지정 범위 본문 디코딩
  • 문서 메타데이터 자동 파싱
  • 줄바꿈 서식 유지 클라이언트 연산
  • 메모리 내 `.txt` 파일 가상 다운로드
워터마크 (Watermark)
  • 텍스트 기입: 폰트 사이즈, 색상, 투명도
  • 9개 레이아웃 포지션 정밀 마운팅
  • 배경 가림 없는 투명도 마스크 레이어
  • 일괄 일점 혹은 다점 도장 찍기 오버레이
페이지 회전 (Rotate)
  • 90°, 180°, 270° 방향별 회전 설정
  • 전체 페이지 혹은 썸네일 체크 일괄 가변
  • 비파괴 회전 후 재정렬 세이브 기능
