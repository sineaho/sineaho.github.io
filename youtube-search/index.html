📊 비율 단계란 무엇인가요?

비율 단계는 [동영상 조회수 ÷ 채널 구독자수] 공식을 통해 산출되는 바이럴 성과 지표입니다. 구독자 수 대비 조회수가 높을수록 해당 채널의 기본 고정 독자층 외의 신규 시청자층에게 대량 노출(알고리즘 추천 등)되었음을 의미합니다.

  • 1단계 (< 0.2): 일반적인 기본 독자층 중 일부만 본 비활성 영상입니다.
  • 2단계 (0.2 ~ 0.6): 구독자 수의 절반 가량이 시청한 보통의 성과입니다.
  • 3단계 (0.6 ~ 1.4): 채널 규모(구독자수)와 거의 1대1 비율로 매칭되는 준수한 바이럴입니다.
  • 4단계 (1.4 ~ 3.0): 구독자 규모를 상회하여 대외 노출이 성공적으로 발생한 인기 급상승 영상입니다.
  • 5단계 (≥ 3.0): 적은 구독자로 수십만 회 이상의 조회수를 낸 초대형 바이럴(대박) 영상입니다. 트렌드 키워드 분석 시 최우선 타겟입니다.

🔑 YouTube Data API v3 Key 발급 방법

  1. Google Cloud Console에 접속하여 새 프로젝트를 생성합니다.
  2. API 및 서비스 > 라이브러리로 이동하여 "YouTube Data API v3"를 검색하고 [사용] 버튼을 클릭해 활성화합니다.
  3. 사용자 인증 정보 탭으로 이동하여 [사용자 인증 정보 만들기 > API 키]를 선택합니다.
  4. 생성된 API 키를 복사하여 이 대시보드 상단 "YouTube API Key" 입력란에 붙여넣고 [API 키 저장]을 누릅니다.
