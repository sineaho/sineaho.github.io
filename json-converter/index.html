JSON & CSV/TSV 포맷 가이드

JSON과 구분자 분할 문서(CSV/TSV)는 데이터 가교 역할을 하는 핵심 구조 규격입니다.

형식별 핵심 요약

  • JSON (JavaScript Object Notation): 속성-값 쌍 또는 배열 데이터 타입을 사람이 읽기 쉬운 텍스트로 표현한 규격입니다. 엄격한 큰따옴표(`"`) 사용과 Key-Value 매칭 규칙을 준수해야 합니다.
  • CSV (Comma-Separated Values): 쉼표(`,`)를 기준으로 레코드를 구분하는 전통적인 텍스트 서식입니다. 쉼표를 값으로 가질 경우 데이터 보정을 위해 쌍따옴표로 값을 감싸서 처리합니다.
  • TSV (Tab-Separated Values): 탭(`\t`) 문자를 구분 기호로 삼는 표 형식 구조 서식입니다. 데이터 필드 내부에 쉼표가 자주 쓰이는 텍스트 문서를 전송하고 정렬할 때 가독성과 안정성이 뛰어납니다.

변환 시 유의점 (FAQ)

  • Q. JSON을 CSV로 바꿀 때 중첩 객체(Nested Object)는 어떻게 처리되나요?

    A. 본 변환기는 중첩된 구조(예: `{ "user": { "name": "Kim" } }`)가 존재할 경우, 문자열 형태인 `[object Object]`로 왜곡되는 것을 막기 위해 `JSON.stringify` 형태로 직렬화하여 한 칸에 깔끔하게 병합시킵니다.

  • Q. 줄바꿈이나 쉼표가 들어간 문자는 CSV 변환 시 문제없나요?

    A. 변환 시 필드값 내에 쉼표나 줄바꿈, 쌍따옴표가 포함된 경우 표준 RFC 4180 규격을 따라 자동으로 쌍따옴표로 감싸주고 내부 쌍따옴표를 이중쌍따옴표(`""`)로 이스케이프 처리하여 데이터 유실을 완벽 방지합니다.
