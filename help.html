CineAHO 홈으로

도움말 및 이용 가이드

시작하기

Cineaho's SandBox에 오신 것을 환영합니다. 다양한 웹 도구를 무료로 사용할 수 있는 플랫폼입니다.

도구 사용 방법

  • 홈페이지에서 원하는 도구를 검색하거나 카테고리별로 찾아보세요.
  • 도구 카드를 클릭하면 해당 도구 페이지로 이동합니다.
  • 각 도구는 별도의 설치 없이 바로 사용할 수 있습니다.
  • 대부분의 도구는 브라우저 안에서 처리되며 무료로 제공됩니다.

카테고리

  • 텍스트 도구: 텍스트 처리 및 분석 도구
  • 웹 도구: URL, JSON, QR, Base64 관련 도구
  • 디자인 도구: 색상, 이미지, UI 관련 도구
  • 계산기: 날짜, 예산, 수식 등 각종 계산 도구
  • 크리에이터 도구: 프롬프트, AI 이미지, Cineaho 콘텐츠 제작 도구

자주 묻는 질문

도구 사용에 제한이 있나요?
공개 도구는 무료로 사용할 수 있습니다. 저장/수집/API가 필요한 일부 기능은 신규 Cloudflare D1/R2 연결 이후 활성화합니다.
회원가입이 필요한가요?
현재 공개 도구는 회원가입 없이 바로 사용할 수 있습니다.
데이터는 안전한가요?
브라우저에서 처리되는 도구는 입력값을 서버로 보내지 않습니다. 서버 저장이 필요한 기능은 별도 안내를 붙입니다.
