API 키 발급 가이드

YouTube Data API v3 발급 방법

  1. Google Cloud 콘솔에 로그인합니다.
  2. 새 프로젝트를 생성하거나 기존 프로젝트를 선택합니다.
  3. [API 및 서비스] > [라이브러리]로 이동하여 "YouTube Data API v3"를 검색하고 [사용]을 클릭합니다.
  4. [API 및 서비스] > [사용자 인증 정보] 탭으로 이동합니다.
  5. [사용자 인증 정보 만들기] > [API 키]를 클릭하면 키가 생성됩니다.

Google Gemini API 발급 방법

  1. Google AI Studio 사이트에 접속하여 로그인합니다.
  2. 왼쪽 메뉴 상단의 [Get API key] 버튼을 클릭합니다.
  3. [Create API key] 버튼을 클릭합니다.
  4. 이용할 프로젝트를 연동하거나 신규 프로젝트에서 키를 만들고, 생성된 API 키를 복사합니다.
